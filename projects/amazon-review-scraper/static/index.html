评论采集使用教程

从第一次采集到导出，几分钟快速上手。

01 · 添加商品与筛选

在采集设置中输入 10 位 ASIN，多个商品可换行或用逗号分隔。选择一个或多个目标市场；深度抓取还可多选星级。“全部”与具体星级互斥。

02 · 选择采集方式与登录

快速扫描读取商品详情页当前展示的评论，适合预览。深度抓取进入评论列表并尝试翻页；采集上限按商品 × 市场 × 星级分别计算。

深度抓取前，打开顶部“站点会话”，为每个市场点击登录。在弹出的浏览器完成登录及评论页认证，再回到工具点击“验证并保存”。采集结束后任务浏览器会自动关闭。

03 · 是否只保留本站评价

勾选“仅保留本站国家/地区的评价”后，按评论中的 Reviewed in… 等地区字段筛选。例如 UK 站只保留英国买家的评价；澳大利亚等其他地区及无法识别地区的评价会剔除。关闭时保留所有地区。

04 · 可选：自动翻译

启用 LLM 自动翻译，选择 OpenAI 兼容或 Anthropic 原生协议，填写接口地址、模型名称、API Key 和目标语言，可先测试翻译连接。采集后自动翻译，也可单独翻译已有结果；原文与译文并排保留。

API Key 只用于本次页面操作，刷新后需重填。评论标题与正文会发送到你填写的接口；切换协议时请核对地址和模型。

05 · 开始、保存与重试

点击开始采集，每读取一页就保存到本机。刷新页面可恢复当前进度；服务意外中断后可恢复最近保存的评论。停止会保留已取得的结果。

在数量摘要中重试所有未完成组合，或在“任务明细”中单独重试。已完成或明确无评论的组合不会重跑。重试从第一页读取并与已有结果合并去重，不保证从中断页继续。

06 · 看懂结果与数量

读取条目 = 重复条目 + 非本站剔除 + 地区未知剔除 + 超上限条目 + 本轮新增。沿用已有表示本轮重试前保留的评论。统计按组合的最近一轮计算，评论总数还会跨星级去重。旧任务没有记录的明细会显示未记录。

达到上限表示主动截断；页面未提供下一页表示当前页面没有可用翻页入口；详情页扫描完成表示只读取了详情页样本。这些状态都不代表已取得亚马逊全部评论。

在评论阅读中搜索标题、正文或作者，按市场和评分筛选。顶部“导出 Excel”保留原文、译文和任务总览，便于后续对比与分析。

常见问题

需要登录或需再次认证？

到站点会话中重新完成对应市场的评论页认证，保存后重试未完成组合。登录成功不一定代表评论列表页已通过认证。

结果为零或数量少于预期？

查看任务明细的结束原因及数量统计，核对 ASIN、市场、星级、地区筛选和上限。访问受限或读取失败会明确显示，不能当成没有评论。

保存失败或意外中断？

出现保存失败提示时，先导出已有结果，再检查磁盘空间和目录权限。重启服务后只会恢复上次成功保存的内容；可重试未完成组合补采。
