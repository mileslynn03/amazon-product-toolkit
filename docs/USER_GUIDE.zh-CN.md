## 使用流程

1. 输入 10 位 ASIN，例如 `B0G92M6VFM`，支持换行、空格或逗号分隔；用复选框选择一个或多个国家站点。
2. 快速扫描读取详情页内嵌评论；数量取决于页面实际内容，不能据此认为取得了全部评论。有已保存会话时会尝试复用。
3. 先输入要抓取的 ASIN，再打开顶部“站点会话”，点击对应市场的“登录”或“验证”。浏览器会打开该商品的评论列表页；请完成此页要求的登录或再次认证，再回到工具点击“验证并保存”。验证会检查该商品的评论是否可读取，不能只凭账户首页可访问判断成功；暂未通过时保留认证页面，允许再次保存。
4. 登录窗口可以取消；等待超过 10 分钟自动结束。抓取与登录互斥，避免浏览器被重复操作。
5. 深度模式支持多个星级复选，全部星级与具体星级互斥。系统按“ASIN × 国家 × 星级”展开任务；1–10000 条的上限针对每个组合。每次最多 500 个组合，兼容“加载更多”和传统下一页。
6. 页面逐商品显示成功、暂无评论、需登录、访问受限、解析失败、翻页未完成等状态。失败或停止时仍保留已经取得的评论。
7. 结果按商品展示，可查看商品图、名称、评分分布，搜索标题、正文或作者，按市场和评分筛选、排序、翻页或展开正文。商品图来自亚马逊页面；页面未提供或访问失败时显示占位图。
8. Excel 包含各个采集组合的总览，以及每个商品和国家的去重明细。重叠星级筛选不会重复累计同一评论；跨国家的记录保持独立。

采集设置中的“仅保留本站国家/地区的评价”默认关闭。开启后，根据每条评论 `review-date` 的原文地区与任务站点匹配，例如 UK 只保留 `Reviewed in the United Kingdom on ...`，剔除 `Reviewed in Australia on ...`。无法识别地区的评价也剔除。多站点按各自地区匹配；快速和深度模式均支持，深度采集上限按筛选后的保留条数计算，整页被筛掉仍继续翻页。此设置作用于下一轮采集，已有结果不自动删除。

结果中的“站点”与“评价地区”分别显示，悬停日期可查看原始地区/日期文本；Excel 同时导出站点、评价标注地区、地区代码和原始日期。旧缓存也能从原日期识别地区。地区指评论字段标注的位置，不据此推断买家的国籍或住址。

界面使用白底与高对比度文字，评论正文在桌面和手机端均为 16px。顶部导航可切换采集设置、结果与站点会话；已有结果时默认折叠设置，点击“采集设置”即可展开。顶部语言菜单支持简体中文和 English，记住本机浏览器的偏好；即时切换会保留采集条件、评论筛选、分页及正文展开状态。商品资料和评论内容保留原文。

已保存会话只代表本地有可尝试的认证信息，界面显示“已保存，待验证”；只有完成在线检查后才显示“登录已验证”。登录、保存和抓取由同一个专用线程执行，成功保存后浏览器会保持打开，继续复用同一个浏览器上下文。请在本轮抓取完成前保留该窗口；整批采集完成、失败或停止后，程序会自动关闭任务浏览器，再更新结束状态。采集结果和已保存的登录文件会保留，下次任务会尝试从文件恢复会话，站点仍可能再次要求认证。单独补读商品资料时，新开的临时浏览器也会自动关闭。

## LLM 评论翻译

在采集设置中勾选“启用 LLM 自动翻译”，填写以下信息：

- **接口协议**：选择 OpenAI 兼容（Chat Completions）或 Anthropic 原生（Messages）。旧配置默认使用 OpenAI 兼容协议。
- **接口地址**：OpenAI 兼容接口可填写 Base URL，例如 `https://your-provider.example/v1`，或完整的 `/chat/completions` 地址；Base URL 只追加 `/chat/completions`。Anthropic 原生接口可填写 `https://api.anthropic.com`、`https://api.anthropic.com/v1` 或完整的 `https://api.anthropic.com/v1/messages`；三者均使用 `/v1/messages`。自定义 Anthropic 网关也可填写根地址、带 `/v1` 的地址或完整 Messages 地址。
- **模型名称**：填写服务商提供的准确模型 ID；**API Key** 填写该服务的密钥，本地免认证模型可留空。
- **目标语言**：与界面语言独立，可选简体/繁体中文、英语、日语、德语、法语、西班牙语、意大利语、葡萄牙语和韩语。
- **每批条数 / 超时**：分别为 1–20 条、5–180 秒，默认 5 条和 90 秒。长评论会自动减少同批条数，不截断原文。
- **Anthropic 输出上限**：仅在原生 Messages 协议下显示，默认 4096 Tokens，可在 128–65536 范围调整，实际值还须符合所选模型限制。输出被截断、拒绝或未完成时会标为失败，可增加输出上限或减小批量后重试。

Anthropic 原生请求使用 `x-api-key` 和 `anthropic-version: 2023-06-01`，系统提示放在顶层 `system`，只解析返回的文本块，不把思考块作为译文。两种协议共同支持连接测试、自动/已有结果翻译、停止、重试和原译文导出。切换协议会清空当前 API Key 和测试状态；自定义网关地址保留，仍需确认地址和模型对应所选协议。

点击“测试翻译连接”会实际发送一小段示例文本。开启后，新任务在采集完成、关闭浏览器后自动翻译标题和正文；也可点击“翻译当前结果 / 重试失败项”，翻译当前整轮全部结果，无需重新采集。

翻译有独立进度与停止按钮。原文始终保留，失败条目标记原因；有效译文按接口、模型、目标语言及原文复用，相同内容只请求一次。重试跳过已成功且配置一致的译文。网络/限流等临时错误最多尝试三次；认证等全局错误停止继续请求。停止会在当前 HTTP 请求返回或超时后生效，已完成译文保留。

页面支持原文/译文对照和译文搜索。Excel 保留原“标题”“正文”列，并在旁边增加“译文标题”“译文正文”，同时导出目标语言、翻译状态、失败说明和模型。译文与进度随结果缓存保存；进程重启后的未完成翻译会标为中断，可以重新发起。

API Key 只在当前页面和请求执行期间的内存中使用，不写入浏览器存储、任务快照、结果缓存、日志或 Excel，刷新后需重新填写。接口和其他非密钥设置记忆在浏览器中。评论标题与正文会发送至用户填写的接口，作者、日期和账号登录 cookie 不进入翻译请求。

接口格式参考 [OpenAI 官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat)和 [Anthropic 官方 Messages 文档](https://platform.claude.com/docs/en/api/messages/create)。两种协议的缓存隔离；已有 OpenAI 译文的缓存键保持兼容。其他服务商可使用其兼容这两种协议的入口。

## 状态恢复与边界

顶部 **“？”** 可打开中英文使用教程，覆盖从 ASIN、市场/星级、登录、评价地区筛选、LLM 翻译到结果阅读和导出的完整步骤，以及认证失败、数量偏少和保存失败的排查说明。教程随界面语言切换，可用关闭按钮、Esc 或点击遮罩退出。

### 中途保存与未完成组合重试

每读取一页就将当前评论和数量明细保存至 `data/last_results.json`，使用临时文件、刷盘和原子替换保护最近一次成功保存的数据。页面显示本机保存时间；写入失败时明确提示，可及时导出当前内存中的结果。意外退出后恢复最近保存的评论，将执行中的组合标为中断。

数量摘要支持“重试未完成组合”，任务明细可单独重试。只执行失败、停止、未执行或中断的组合；已完成和明确无评论的组合保持不变。沿用原市场、星级、地区和上限条件，保留已有评论、商品资料与译文。重试从第一页重新读取，再按评论 ID（无 ID 时按原文指纹）合并去重，不提供精确页码续传；原文变化时清除该条旧译文，避免错配，可重新翻译。

### 数量与结束原因

数量按每个组合的最近一轮执行记录：`读取条目 = 重复条目 + 非本站剔除 + 地区未知剔除 + 超上限条目 + 本轮新增`。沿用已有为重试开始前保留的评论，组合保留为最终结果数。组合之间再次按商品和站点去重，因此组合保留数之和可能大于页面显示的唯一评论数。旧任务缺少明细时标明未记录，不推算历史读取量。

任务明细和 Excel 总览记录达到上限、页面未提供下一页、详情页扫描完成、明确无评论、手动停止及各类错误等结束原因。前三种均不保证取得了亚马逊全部评论。Excel 额外包含执行轮次及本轮数量列，旧结果的未知统计留空。

- 页面刷新和 SSE 重连会自动恢复当前服务进程内的任务、结果和登录阶段。
- 最近一轮任务按页保存在 `data/last_results.json`，重启服务恢复结果与商品信息，未完成组合可重试；登录阶段不会被误恢复为已验证。仍建议及时导出重要研究数据。
- 停止操作在轮询、翻页和限速等待中检查取消信号；正在进行的页面导航需要等请求返回或超时。
- 验证拦截、HTTP 错误、过期登录和无法识别的页面都会明确报告失败。只在页面明确显示无评论时报告“暂无评论”。
- 遇到验证拦截后，可通过登录窗口手动完成验证和登录，再重新启动抓取。程序不会自动绕过验证。
- 20 个站点有域名配置，尚未逐站完成真实页面验收。真实采集、数据恢复与自动化测试的验证范围见[当前验收状态](VERIFICATION.md)；历次修复见[历史记录](history/REPAIR_NOTES.md)。
- 登录态位于 `storage/login_state_<code>.json`，按站点隔离。
- 请遵守站点访问规则，合理控制请求频率。

## 一键启动与退出

先按[首页的运行环境说明](../README.zh-CN.md#运行环境)安装 Python，并将项目完整解压到有写入权限的目录。Windows 双击 `start_windows.bat`；macOS 双击 `start_macos.command`。首次可选择终端提示语言：输入 `1` 为中文、`2` 为英语，回车默认中文。网页语言在顶部独立选择，评论译文的目标语言在 LLM 设置中独立选择。

启动器会创建 `.venv`，安装 Python 依赖与 Playwright Chromium，等待本地服务就绪后打开页面。首次安装需要联网，耗时取决于下载速度；日后复用环境，依赖文件变化或 Chromium 缺失时再安装。不会自动安装系统 Python，不需要 Node.js、Docker 或数据库。

服务只监听本机，默认地址为 http://127.0.0.1:8000/ 。使用期间保留启动终端。需要退出时，先停止正在运行的采集或翻译，等待结果保存，再在启动终端按 **Ctrl+C**；直接关闭终端可能只能保留最近一次成功保存的内容。关闭网页标签页不会停止服务。重复运行启动器会复用同目录的服务。

### 启动参数

以下参数同时适用于两个启动脚本。在项目目录打开终端；Windows 使用 `start_windows.bat`，macOS 使用 `bash start_macos.command`。

| 参数 | 含义 |
| --- | --- |
| `--lang zh` / `--lang en` | 指定终端提示语言，跳过语言选择 |
| `--setup-only` | 只准备环境，不启动服务或打开网页 |
| `--check` | 检查当前环境是否就绪，不安装、不启动 |
| `--no-open` | 启动服务但不自动打开默认浏览器 |
| `--port 8001` | 使用其他端口，手动访问 http://127.0.0.1:8001/ |

Windows 示例：

```bat
start_windows.bat --lang zh
start_windows.bat --lang en --setup-only
start_windows.bat --lang zh --port 8001
```

macOS 示例：

```bash
bash start_macos.command --lang zh
bash start_macos.command --lang en --check
bash start_macos.command --lang en --port 8001
```

## 常见问题与排查

### 未找到 Python，或 Python 版本不符合要求

先从 [Python 官网](https://www.python.org/downloads/)安装 64 位 Python，推荐 3.11 / 3.12。Windows 安装时保留 Python 启动器，并在安装器提供该选项时启用 Add Python to PATH。安装后重新打开终端再运行脚本。仅下载源码包无法直接运行本项目。

### macOS 双击提示权限问题

先完整解压项目，在终端进入项目文件夹，执行一次：

```bash
chmod +x start_macos.command
./start_macos.command
```

也可直接用 `bash start_macos.command`。如果系统拦截下载的脚本，请核对仓库来源，再按 macOS 自身提供的提示允许本次打开；无需关闭系统安全设置。

### 依赖或 Chromium 下载失败

保留终端错误，确认网络可以访问 PyPI 和 Playwright 下载服务，网络恢复后重新运行；失败安装不会被标记为完成。启动器会沿用环境变量中的代理；Windows 的系统 HTTP / HTTPS 代理也会传给安装子进程，不写入项目配置。公司网络需要专用代理或证书时，按网络管理员提供的方法配置，不建议关闭 TLS 校验。

### 端口 8000 被占用

同一份项目已由新版启动器启动时会直接打开已有服务。其他程序、另一份项目或旧版手动服务占用端口时会提示，不会强行终止它们。可关闭对应服务，或加 `--port 8001`，之后使用提示的新地址。

### 虚拟环境损坏，或更换电脑 / 系统后不能启动

不要复制 `.venv` 到另一台电脑。先关闭当前项目服务，将 `.venv` 重命名为 `.venv.backup`，再运行启动器创建新环境。保留 `data/` 和 `storage/`，不要为了修复环境删除评论或登录会话。

### macOS Python 出现证书校验错误

使用 python.org 安装器的用户可查看该 Python 安装目录中的 `Install Certificates.command`，按 [Python macOS 官方说明](https://docs.python.org/3/using/mac.html)完成证书安装，再重新运行启动器。

### 抓取失败或翻译失败

先查看页面“任务明细”和顶部“？”教程。评论页需再次认证时，通过对应市场登录并保存，再重试未完成组合。LLM 错误先核对协议、地址、模型、密钥和输出上限；停止或失败不会删掉原文。不要把 API Key、登录会话或包含个人信息的完整截图粘贴到公开 Issue。

## 更新和本地数据

通过 Git 安装的用户，可在停止服务后运行 `git pull`，再双击启动脚本；依赖变化时会自动重新检查。通过 ZIP 安装的用户，将新版解压到新文件夹，按需在服务停止后迁移原来的 `data/` 和 `storage/`，再启动。勿迁移 `.venv`。

`data/last_results.json` 保存最近一轮结果；`data/launcher.lock` 是安装互斥锁文件，保留它即可；`storage/login_state_<code>.json` 含各站点登录会话；`.venv` 为本机依赖环境。这些目录均被 Git 忽略。
